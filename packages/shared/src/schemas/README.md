# Shared Schemas

This directory contains domain schemas and validation rules shared across frontend (`apps/web`) and backend (`apps/api`).

## Structure (Future)

- `user.schema.ts` — Authentication & user profile schemas
- `academic.schema.ts` — ASTU academic work schemas
- `projects.schema.ts` — Final project & EDOT schemas
- `tasks.schema.ts` — Goals, milestones, tasks, dependencies
