# Domain Boundaries — KENENISA OS

KENENISA OS models 10 system domains:

1. **Academic (ASTU):** Course registration, syllabus, assignments, exams, GPA calculation engine.
2. **Individual Final Project:** Research proposal, milestones, implementation deliverables, advisor feedback.
3. **Group Final Project:** Team roles, shared tasks, repository commit integration, sprint status.
4. **Full-Stack Engineering:** Architecture design, feature implementation, code quality metrics.
5. **AI Engineering:** Paper summaries, model fine-tuning experiments, RAG evaluation logs, prompt library.
6. **EDOT Product:** SaaS product roadmap, feature requests, deployment telemetry.
7. **Management Studies:** Leadership frameworks, agile sprint retrospectives, organization notes.
8. **Freelance & Consulting:** Client management, deliverables, invoicing, time tracking.
9. **Personal Brand:** Blog posts, open-source projects, speaking engagements, CV updates.
10. **Productivity Analytics:** Goal hierarchy (Goal -> Milestone -> Task -> Subtask), time logging, evidence upload, AI planner.
